Prototype [02] // DOCS_AUTOMATION

Self-Healing Docs

Push-to-PR documentation pipeline

Watches a repo's pushes, finds exactly which functions changed, and opens a pull request that updates the docs describing them. Every patch passes three guardrail layers, and anything unsafe is escalated to a human instead of guessed at.

Diffing
tree-sitter AST
Guardrails
3 layers
Tests
43 + CI
PythonFastAPIPineconeGeminiDockerGitHub Actions
Open breakdownClose breakdown
  • Verified GitHub push webhooks with HMAC-SHA256 and constant-time comparison, then processed each job in the background so GitHub never times out.
  • Function-level diffing with tree-sitter classifies each change as signature, body-only or both, then embeds one chunk per function with Gemini into a per-repo Pinecone namespace.
  • An LLM proposes a structured patch that must pass two deterministic checks (verbatim match, scope) and an LLM-as-judge, with two bounded retries before escalating to a draft PR.
  • Re-verifies each patch against the live file before applying, and ships containerized with a 43-test suite running in CI on every push.
